## 🧱 This repo

[didierkrux.com](https://www.didierkrux.com/): an Astro static site with one React island, a 3D Meebit that dances to Digital Krux sets, and a voxel world going up in public. Deployed on Vercel.

    pnpm install
    pnpm dev            # http://localhost:4321/
    pnpm test           # unit tests (Vitest)
    pnpm test:e2e       # end-to-end (Playwright, builds first)
    pnpm check          # Astro type check

Everything you read on the site lives in `src/content/` as YAML: projects, roles, education, profile, copy. Edit a file, save, the dev server reloads. Schemas are in `src/content/schema.ts`; a bad field fails the build.

Generated files are committed; regenerate them when their sources change:

    pnpm import:episodes   # Digital Krux sets from digitalkrux.com/api/episodes.json
    pnpm resume:pdf        # prints /resume to public/Resume_Didier_Krux.pdf
    pnpm og:images         # screenshots social previews into public/og/
    pnpm import:animations # fetches the Mixamo clips the Meebit uses

`rebuild` is the new site (Vercel preview), `master` is production. The previous site is kept in `archive/2018-site/` for reference and is not deployed. Third-party assets and their licenses are listed on [didierkrux.com/manual](https://www.didierkrux.com/manual).
